# Instrucciones para agentes

Este archivo solo existe para que cada herramienta de IA encuentre la misma guía. No agregues
reglas aquí.

1. Lee `AGENTS.md`: cómo trabajar en este repositorio. Es la fuente única y la usan todos los
   agentes (Codex, Claude, Gemini, Copilot y otros).
2. Lee `ESTADO.md`: cómo está todo hoy, qué está pendiente, las preferencias del usuario y la
   bitácora histórica.
3. Al terminar cualquier cambio, actualiza `ESTADO.md` (y `AGENTS.md` si cambió la forma de
   trabajar) en el mismo commit.
